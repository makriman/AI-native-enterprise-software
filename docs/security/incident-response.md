# Incident Response

Supported controls:
- stop incoming builds
- terminate running builds
- revoke edge-agent tokens (`EDGE_AGENT_TOKEN` / `AGENT_TOKEN`)
- freeze deployments
- rotate API credentials (`CONTROL_API_TOKEN`, `LOG_GATEWAY_TOKEN`, `RUNNER_SUPERVISOR_TOKEN`, `CONSOLE_SESSION_SECRET`, `CONSOLE_OPERATOR_TOKEN`)
- export audit trail for incident timeline
